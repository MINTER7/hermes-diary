# Diary preferences

- Respond and record in the user's language; preserve names, meaning and concrete facts.
- Keep each entry to a short sentence. Do not invent feelings, reflections or missing details.
- Record events that actually happened. Questions, hypotheticals and setup discussions are not events.
- Use the diary context clock, unless the user explicitly supplies the event time.
- Update the city only for a stated arrival or current location. Never geolocate automatically.
- Preserve append order; do not deduplicate, reorder, delete or translate existing notes automatically.
- Preview without delivery. Send only when requested or under an explicitly enabled schedule.
- Manage heading language, weather, temperature unit, destination and schedule through configuration.
